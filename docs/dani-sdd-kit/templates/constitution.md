# DANI engineering constitution
1. One agent owner (Hermes), tiny deterministic runtime, optional decision coprocessor.
2. One enforceable side-effect broker; no bypass through arbitrary credentials/shell/network.
3. State ownership and typed API contracts; migrations and backward compatibility.
4. Feature parity with existing DANI, no unnecessary rewrite, preserve required licenses/notices.
5. Measured verified completion and resource consumption, not hypothetical speed.
6. RED/GREEN/REFACTOR, contract and adversarial tests, real platform evidence.
7. Explicit user control, scoped approvals, trustworthy job outcomes and recoverable cancellation.
8. Memory never substitutes for authoritative state or current approval.
9. No hidden installs, unapproved spending, cross-user leakage or unsafe autonomous execution.
10. Verify before declaring complete; feature flag and rollback for risky changes.

Version: 1.0; changes require ADR and reviewer agreement.
